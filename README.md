# Dafan 4K Enhancer

تطبيق سطح مكتب لنظام Windows لتحسين الصور بنماذج super-resolution عصبية، وتحجيم الفيديو محليًا باستخدام FFmpeg. الواجهة تدعم العربية والإنجليزية. لا يرفع التطبيق ملفاتك إلى الإنترنت.

## ما الذي يعمل فعليًا؟

- **الصور:** استدلال OpenCV DNN محلي على CPU باستخدام FSRCNN بمقياس 2× أو LapSRN بمقياس 4×. تُنزّل أوزان النموذج عند الحاجة وتُتحقق بصمة SHA-256 قبل استعمالها. يدعم PNG وJPG/JPEG وWEBP وBMP وTIFF، والدفعات، والمعالجة المتتابعة، والمحافظة على الأصل، ومنع الكتابة فوق النتائج السابقة. تُقسّم الصور الكبيرة إلى رقع لتقليل الذاكرة. يمكن تفعيل مرشح إزالة تشويش خفيف قبل الاستدلال.
- **الفيديو:** FFmpeg يعمل على تدفق الإطارات بدل تحميل الفيديو كاملًا إلى الذاكرة. يخرج MP4/H.264 بارتفاع 1080 أو 1440 أو 2160 بكسل أو ارتفاع يدوي بين 240 و4320، مع إعداد CRF ومعدل إطارات اختياري، وخيار نسخ الصوت الأصلي أو تحويله إلى AAC. يمكن إلغاء المهمة الحالية أو إيقاف القائمة.
- **الواجهة:** قائمة انتظار، تقدم للمهام، إحصاءات للحالات، معاينة قبل/بعد للصورة، سجل للنتائج المكتملة، اختيار مجلد إخراج، إعادة محاولة الفاشل، إعداد حجم رقع الصور (256/512/768 بكسل)، إعدادات محفوظة، والتحويل بين العربية والإنجليزية.

**تنبيه دقة مهم:** مقياس الفيديو هو تحجيم Lanczos تقليدي وليس تحسينًا عصبيًا. لا يوجد في هذا الإصدار نموذج AI للفيديو. أما صور AI فقد تنشئ تفاصيل تقديرية، ولا تستعيد معلومات غير موجودة في الصورة الأصلية. وضع GPU غير مفعّل؛ الاستدلال الحالي CPU لتوافق أوسع. تعالج المهام بالتتابع للمحافظة على الذاكرة.

لا يتضمن هذا الإصدار حاليًا السحب والإفلات، أو تقدير الوقت المتبقي، أو إيقافًا مؤقتًا، أو إعدادًا لعدد المهام المتزامنة. اختيار الملفات يتم عبر نوافذ النظام، ويمكن إلغاء المهمة أو إيقاف القائمة. تقدم النماذج وDNN يعتمد على معالج CPU؛ يتوفر تحديد حجم الرقع لتقليل الذاكرة. لم أتمكن من التحقق من بناء Windows من داخل Sandbox Linux؛ التحقق النهائي من EXE يتم بخطوة الاختبار الذاتي في workflow على GitHub Actions.

## المتطلبات

للتشغيل من المصدر: Windows 10/11، Python 3.11 (مُختبر في workflow)، وذاكرة كافية لحجم الصورة/الفيديو. اتصال الإنترنت مطلوب فقط لتنزيل نموذج الصورة لأول مرة. FFmpeg المضمّن يأتي من حزمة `imageio-ffmpeg`؛ يمكن استعمال تثبيت FFmpeg الموجود في PATH بدلًا منه.

تُحفظ الإعدادات والنماذج في مجلد بيانات المستخدم:

- Windows: `%APPDATA%\Dafan4KEnhancer\`
- الأنظمة الأخرى: `~/.local/share/Dafan4KEnhancer/` (أو `$XDG_DATA_HOME/Dafan4KEnhancer/`)

## تشغيل من المصدر

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python app.py
```

في أول استخدام للصور، اختر مقياسًا واضغط بدء؛ ينزل التطبيق النموذج من مستودع بيانات OpenCV الرسمي ويتحقق من SHA-256. يمكن تنزيل النموذجين مسبقًا من صفحة **الإعدادات وحول**. بعد تنزيل النماذج، تحسين الصور محلي ولا يحتاج إلى اتصال بالإنترنت.

## بناء EXE بواسطة GitHub Actions

1. أنشئ مستودعًا جديدًا على GitHub وارفع محتويات هذا المجلد إلى الفرع `main` أو `master`.
2. افتح تبويب **Actions** في المستودع. إذا طلب GitHub تفعيل Actions، فعّلها لهذا المستودع.
3. سيعمل workflow المسمى **Build Windows EXE** عند push أو pull request، ويمكن تشغيله يدويًا من **Actions → Build Windows EXE → Run workflow**.
4. تحقق من نجاح خطوات تثبيت الاعتمادات والاختبارات وبناء PyInstaller.
5. افتح تشغيل workflow الناجح، ثم قسم **Artifacts** ونزّل `Dafan4KEnhancer-Windows-x64`. فك ملف ZIP وشغّل `Dafan4KEnhancer.exe`.

ينتج الـworkflow حزمة Windows x64 في GitHub Actions Artifact. لا تُضمّن أوزان الشبكات داخل Git؛ تنزل عند التشغيل وتُفحص سلامتها. مدة الاحتفاظ بالـArtifact تخضع لإعدادات GitHub للحساب/المستودع. لم يُبنَ EXE داخل بيئة Linux الحالية؛ يجب أن ينجح workflow على Windows قبل اعتبار الحزمة المنشأة صالحة.

## الخصوصية والتراخيص

لا يرسل التطبيق ملفات المستخدم إلى خادم. تنزيلات النماذج تتم من مستودع [opencv/opencv_extra](https://github.com/opencv/opencv_extra) عبر HTTPS مع تحقق ثابت من SHA-256. يوضح [توثيق OpenCV DNN Super Resolution](https://docs.opencv.org/4.13.0/d5/d29/tutorial_dnn_superres_upscale_image_single.html) طريقة استعمال النماذج. OpenCV مرخص بموجب Apache-2.0، لكن تراخيص أوزان النماذج قد تختلف عن ترخيص التطبيق؛ لذلك لا تُضمّن الأوزان في حزمة التوزيع. حزمة FFmpeg المُضمّنة عبر `imageio-ffmpeg` تخضع لترخيص بناء FFmpeg المرفق بها؛ راجع ملفات التوزيع الأصلية قبل إعادة توزيع التطبيق تجاريًا.
